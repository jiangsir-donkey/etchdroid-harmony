# 授权证据存档（permission evidence）

这个目录专门放**"已获上游作者许可"的证据**。提交华为应用市场时，它就是
"审核备注"里要附的那份材料。

## 该放什么

| 文件 | 说明 |
| --- | --- |
| `20YY-MM-DD-discussions-post.png` | 你发出申请的讨论页整页截图（含 URL 与时间） |
| `20YY-MM-DD-reply.png` | 对方回复的截图（**关键证据**，别裁剪掉用户名和时间戳） |
| `RECORD.md` | 下面这个模板，用人话把结论写下来 |

原则：**原始截图不要裁剪**、不要只存文字转述。对方 GitHub 用户名、时间戳、
permalink 链接都要完整可见。

---

```markdown

- 申请链接（permalink）：https://github.com/EtchDroid/EtchDroid/discussions/___
- 申请发出时间：20YY-MM-DD
- 对方回复时间：20YY-MM-DD
- 对方账号：@depau

## 结论

（三选一，删掉其余）

- [ ] **已获许可**：同意在鸿蒙移植版中继续使用 "EtchDroid" 名称与图标。
- [ ] **有条件许可**：条件为 ___，已逐条落实（逐条写清如何落实）。
- [ ] **未获许可 / 未回复**：已按 B 方案改用独立名称「___」与自绘图标。

## 对方原话（原文摘录，不要翻译后只存译文）

> 粘贴原文

## 我方落实

- [ ] 应用名称：___
- [ ] 图标：___（是否已与上游区分）
- [ ] App 内「关于」页非官方声明：已保留

- [ ] README / NOTICE 已同步更新
```

---

## 特别提醒

- **没有回复 ≠ 有许可。** 未获回复时，商店描述里**绝不能**出现"官方""正版"
  "已获作者授权"等字样——那属于虚假陈述，性质比商标问题本身更严重。
- 拿到了许可也要**继续履行 GPLv3**：公开发布对应源代码、保留版权声明、
  不得闭源。授权解决的是商标，不是 GPL 义务。
- 本目录内文件会随仓库公开。如果聊天记录里含有你的隐私信息（手机号、
  个人住址等），请先打码再放进来。
